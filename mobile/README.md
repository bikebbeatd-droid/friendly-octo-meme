# Airgorah Mobile

The supplied file is a Debian Linux ARM64 package, not an Android APK. Its GTK4 GUI, Linux executables, and PolicyKit integration cannot simply be copied into Android.

This mobile project provides an Android foundation with a phone-friendly UI and current Wi-Fi information. It intentionally does not implement offensive Wi-Fi actions such as deauthentication or password cracking.

A fuller legitimate mobile audit app can add permission-aware network inventory, diagnostics, signal information where Android permits it, and report export for networks the user owns or is authorized to test.
